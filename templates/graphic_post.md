## 发布前检查

- [ ] 第一张图在3秒内能看懂主题
- [ ] 第一张图先讲目标用户、痛点和结果，而不是先堆AI术语或芯片参数
- [ ] 每张图只有一个核心信息
- [ ] 默认 3 张；扩展到 4-5 张时，每张都有不可合并的新信息
- [ ] 至少一张图包含真实证据或可核验来源
- [ ] 标题中的数字、项目名、结果都有正文依据
- [ ] 标题和第一屏共同服务于一个预期读者动作
- [ ] 正文交付了来源、边界和下一步
- [ ] 产品内容讲清了用户、场景、痛点、替代方案、AI方案、端侧价值和商业证据
- [ ] 小红书配文没有微信专属话术
- [ ] 公众号长文若存在，固定结尾只出现一次
- [ ] 图片已检查中文字体，没有“？？？”乱码
